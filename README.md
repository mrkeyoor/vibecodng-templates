# vibecodng templates

35 complete React and Vite page starters from the public [vibecodng template library](https://vibecodng.com/templates/).

Each template is a standalone project with its own `package.json`, `TEMPLATE.md`, license, responsive layout, and source-attribution notes. The library includes:

- 8 general starters for landing pages, apps, agencies, docs, ecommerce, portfolios, and local businesses
- 15 visual-style starters, including brutalism, glassmorphism, spatial, editorial, 3D, and neumorphism
- 12 industry starters for clinics, finance, construction, education, hospitality, law, fitness, and more

## Use one template

```bash
npx degit mrkeyoor/vibecodng-templates/templates/landing-01 my-site
cd my-site
npm install
npm run dev
```

Replace `landing-01` with any directory under [`templates/`](./templates). Browser previews, source downloads, filters, detail pages, and palette variants are available at [vibecodng.com/templates](https://vibecodng.com/templates/).

## Quality notes

The public defaults are built and checked at a 375px viewport for HTTP success, horizontal overflow, browser errors, and automated axe findings. A clean automated audit is useful evidence, not an accessibility certification; test your customized content and flows before production use.
