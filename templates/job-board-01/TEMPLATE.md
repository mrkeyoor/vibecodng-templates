# Practice

Practice is a focused job-board template with keyword and location search, role-type filters, saved jobs, selectable listings, salary and workplace metadata, a detailed role panel, employer trust signals, and a responsive application journey.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the jobs workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```

## Palette contract

The template uses `--bw-accent`, `--bw-surface`, `--bw-text`, and `--bw-muted`. Pass a JSON palette through `BW_PALETTE` during a Vite build to create a themed variant.
