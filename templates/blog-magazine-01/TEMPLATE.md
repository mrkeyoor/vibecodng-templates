# Relay Review

Relay Review is a typography-led magazine and newsletter template with an issue masthead, category filters, featured reporting, article cards, reading-time metadata, a working newsletter state, a trending rail, and responsive editorial hierarchy.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the magazine workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```

## Palette contract

The template uses `--bw-accent`, `--bw-surface`, `--bw-text`, and `--bw-muted`. Pass a JSON palette through `BW_PALETTE` during a Vite build to create a themed variant.
