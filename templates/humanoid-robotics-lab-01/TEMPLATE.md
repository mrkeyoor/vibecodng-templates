# Humanoid Robotics Lab

A cinematic React/Vite brand template for a fictional embodied-autonomy company. Its signature movement score lets visitors wake a humanoid body, direct it through four physical cues, inspect its sense field, and tear off a first-shift ticket.

## What makes it distinct

- Borderless orange body-theatre with a procedural React Three Fiber humanoid, giant kinetic type, and task-specific pose, gaze, sensor field and reach-target changes
- Seven distinct cinematic compositions: movement score, human-scale image curtain, orbital sense field, full-bleed warehouse transcript, tactile macro, stopping ritual, and tear-off shift ticket
- A purpose-built mobile composition with a lightweight code-native articulated robot fallback instead of a squeezed desktop canvas
- Stateful work choreography, sensor selection, and a first-shift workflow with an inline confirmation outcome
- Three coordinated original AI-generated editorial assets, stored locally and used for different narrative roles
- Honest simulated robotics data and no copied hardware, trademarks or live-performance claims
- Semantic palette injection through `BW_PALETTE`, reduced-motion support and keyboard-operable controls

## Run

```bash
npm install
npm run dev
npm run build
```

## Asset provenance

`public/robotics-calibration.webp`, `public/robotics-workcell.webp`, and `public/robotics-gripper.webp` were generated specifically for this template with OpenAI image generation on 2026-08-20, inspected, then optimized locally. They depict fictional unbranded hardware and must not be represented as photographs of a real product or deployment.

## Palette support

The Vite configuration reads a complete `BW_PALETTE` JSON object and injects semantic color variables. Default, `paper-coral`, and `aurora-terminal` are the representative review worlds. Black, paper, cyan, and safety orange are used as deliberate cinematic production colors while semantic foreground and surface variables remain palette-aware.

## Production budget

The hero uses React Three Fiber for one domain-native signature engine. The documented review budget is 380 KB gzip so the 3D runtime can remain real rather than becoming decorative video; mobile hides that WebGL surface in favor of the code-native fallback, and reduced-motion removes scroll-linked transforms.

## Data note

All cycle times, reach values, payloads, stop distances, sensor rates, readiness scores and confirmation codes are illustrative template data.
