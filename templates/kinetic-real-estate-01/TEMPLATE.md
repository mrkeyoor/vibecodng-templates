# ORRA — Kinetic Real Estate 01

A cinematic luxury real-estate presentation for a fictional residence carved into a desert escarpment.

## Experience

- Scroll-controlled bronze-screen opening and three-scene property narrative
- Architectural floor plan and material story
- Space collection and destination section
- Functional private-viewing enquiry drawer with confirmation state
- Responsive layouts, reduced-motion support and keyboard-visible focus states
- Build-time VibeCodng palette injection

## Run

```bash
npm install
npm run dev
```

All property imagery is original AI-generated artwork for this fictional concept. No real property, agency or architect is represented.
