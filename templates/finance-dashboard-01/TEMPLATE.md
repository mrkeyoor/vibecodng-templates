# Ledgerline

A business banking dashboard with account switching, cash-flow visualization, searchable transactions, budget insights, and a working transfer flow.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the finance workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```
