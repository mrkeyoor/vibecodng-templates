# Relay

A focused support inbox with ticket filters, searchable conversations, customer context, reply composer, priority states, and resolution actions.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the support workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```
