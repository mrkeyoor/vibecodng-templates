# SILLAGE / Interactive Accord Composer

An original fine-fragrance campaign organized around top, heart and base note evolution rather than a product grid.

The signature accord chamber changes three liquid strata, atmospheric color, diffusion language, formula and a fictional blotter outcome. Mobile becomes a thumb-readable perfumer blotter wallet.

All four campaign photographs were generated for this template and stored as optimized local WebP assets. The template supports `BW_PALETTE`, keyboard use, 320px reflow, 200% text zoom, reduced motion and honest fictional-sample language.
