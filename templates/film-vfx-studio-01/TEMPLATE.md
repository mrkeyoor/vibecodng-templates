# Cutline Assembly — Film & VFX Studio

An original full-page template for an independent direction, production and visual-effects studio. Its core metaphor is a cut that assembles: visitors move through a working reel, inspect a practical-to-final VFX breakdown, and turn project choices into a concise treatment before contacting production.

## Signature features

- Desktop monitor wall with a live shot queue, safe-area guides and production metadata.
- Selectable reel timeline with meaningful frame, lens, build and director-note changes.
- Three-step treatment desk resolving into a portable call sheet.
- Explicit plate/final VFX comparison with a non-drag control.
- Live 144-frame canvas compositing timeline with four independently switchable finishing layers.
- Motion is functional: frame readouts transition on deliberate input, with no autoplay or decorative loop.
- Production capability ledger and fully validated enquiry handoff.
- Purpose-built mobile director-monitor composition, numbered shot navigation and one-prompt treatment flow.
- Reduced-motion, keyboard, 200% text scaling and semantic palette support.

## Assets and provenance

`still-arrival.webp`, `still-signal.webp` and `still-crossing.webp` are original AI-generated bitmap assets created for this template with the built-in OpenAI image-generation tool on 2026-08-19. They form one fictional, coherent nocturnal science-fiction sequence. Each image is local, WebP-optimized, below the house raster budget, and used in its mapped narrative role. The project contains no copied client work, stock photography, external fonts or runtime asset dependencies.

All studio names, credits, availability, project data and production statistics are illustrative sample content.

## Palette support

The Vite build reads `BW_PALETTE` and maps `accent`, `surface`, `text` and `muted` values into semantic CSS variables. Default, `paper-coral` and `aurora-terminal` are the representative review worlds.
