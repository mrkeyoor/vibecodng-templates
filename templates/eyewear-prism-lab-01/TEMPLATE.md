# PRISM / Eyewear Spectrum Lab

An original optical-fashion campaign built around a live spectrum lab, frame geometry, tint transmission and a fictional fitted-view outcome.

## Signature interaction

Choose frame geometry, lens tint and ambient light. The scene, glare-control score, transmission data and fitting receipt update as one system. Mobile reframes this as an optician test card with one-eye controls.

## Assets

All four campaign photographs were generated specifically for this template and stored locally as optimized WebP files. No third-party photographs or external image dependencies are used.

## Palette and access

The template supports the Vibecodng `BW_PALETTE` injection, keyboard focus, 320px reflow, 200% text zoom, reduced motion and explicit fictional-commerce language.
