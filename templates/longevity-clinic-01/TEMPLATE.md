# North / Now · Longevity Clinic

An original physician-led healthspan template built as a clinical care-file system. Desktop uses a simultaneous triage board, contextual evidence ledger, care-pathway matrix, 90-day cadence and inline consultation handover. Mobile is purpose-built as a progressive four-question “pocket care passport” rather than a collapsed desktop page.

The flagship interaction assembles priority, pace, setting and review cadence into a deterministic, editable starting brief. Form validation and confirmation are local demo states and make no external request.

The fictional content is evidence-minded and avoids diagnostic, biological-age and guaranteed-outcome claims. Four coordinated WebP assets are bundled locally and each has a single editorial role; there are no external runtime fonts or expiring assets. Semantic `BW_PALETTE` tokens support the default, representative light and representative dark builds.

## Quality review

`quality.scenario.mjs` covers the care index lifecycle, complete brief assembly, context/pathway/cadence controls, FAQ, invalid consultation state and successful confirmation on mobile and desktop.

## Run

`npm install && npm run dev`
