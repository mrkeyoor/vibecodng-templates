# VECTOR 01 — Performance Footwear

An original performance-running template built as a force chassis that separates. Its signature interaction is a real-time Three.js shoe assembly: visitors rotate the model, split its upper, carrier and outsole, and move it through touchdown, midstance and toe-off before resolving terrain, strike and ride inputs into a transparent edition recommendation.

Desktop presents a WebGL optical bay between a specimen docket and simultaneous force console. Mobile becomes a thumb-operated run dial with explicit non-drag rotation, phase and layer controls, followed by the one-question gait scanner and a selected-edition field ticket.

## Motion and 3D

- `@react-three/fiber` and `three` construct the code-native shoe, its exploded assembly and phase-specific force ring.
- Framer Motion provides short state transitions for phase and material readouts.
- The model has keyboard/touch buttons for every drag action.
- Reduced-motion mode disables drag-driven travel, freezes the WebGL rig in a useful pose and keeps every state reachable through controls.
- The WebGL experience intentionally uses a larger JavaScript budget than a static marketing template; no 3D bitmap sequence or video payload is shipped.

## Assets

`public/vector-01-lab.webp` is an original AI-generated product still created for this template with OpenAI image generation. It depicts a fictional, unbranded shoe and is used only as below-fold material evidence. The hero product, force path, diagrams and readouts are code-native.

## Palette support

Semantic tokens support the default calibration-paper world and the `paper-coral` and `aurora-terminal` `BW_PALETTE` builds.

## Run

```bash
npm install
npm run dev
npm run build
```

No interaction sends external data. Product numbers and recommendations are fictional demonstration content.
