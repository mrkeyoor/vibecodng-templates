# APEX WORKS — Motorsport Team

An original elite motorsport template built as a pit wall that calls strategy. The hero behaves like a race broadcast command surface rather than a car configurator. The flagship interaction models tyre compound, pit lap, weather and traffic into an explained fictional strategy outcome.

Desktop uses simultaneous timing rails, circuit trace and controls. Mobile is a separate one-hand race-engineer radio stack with four sequential prompts and an in-flow strategy ticket. The paddock-interest flow validates locally and makes no network request.

Its new signature telemetry lab links a moving circuit marker, explicit race clock, three sector calls and Speed/Brake/Energy traces. Nothing autoplays: every movement communicates an engineer decision.

## Asset

`public/apex-race-control.webp` is an original AI-generated documentary race still created with OpenAI image generation for this template. It depicts a fictional unbranded team and circuit and is used only in the hero. Track and telemetry graphics are code-native.

## Palette support

Supports semantic `BW_PALETTE` builds, including representative `paper-coral` and `aurora-terminal` palettes.

## Run

`npm install && npm run dev` or `npm run build`.

All timings, classifications and strategy projections are fictional demonstration data.
