# VERDANT editorial motion template

An art-directed botanical skincare template with atmospheric image motion, ingredient storytelling, editorial type, scroll-revealed products, ritual selection, and a functional add-to-bag flow.

## Art direction

The campaign image is original AI-generated project artwork created for this template. It is stored locally and has no runtime dependency.

## Interaction

- Sticky cinematic hero with scroll-linked scale and copy movement
- IntersectionObserver content reveals with reduced-motion support
- Layered product chapters and horizontal snap collection
- Working navigation, menu, bag, and add-to-bag interactions
- Five palette builds through the vibecodng palette contract

## Run

```bash
npm install
npm run dev
```
