# Foundry Market

Foundry Market is a warm editorial marketplace template with live search, category filters, saved products, price and maker metadata, a featured collection, trust notes, responsive product cards, and conversion-focused browsing without visual clutter.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the market workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```

## Palette contract

The template uses `--bw-accent`, `--bw-surface`, `--bw-text`, and `--bw-muted`. Pass a JSON palette through `BW_PALETTE` during a Vite build to create a themed variant.
