# Keystone

A calm, functional CRM with pipeline stages, lead search, opportunity details, activities, owner context, and an add-opportunity workflow.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the crm workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```
