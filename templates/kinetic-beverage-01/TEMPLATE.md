# PULSE kinetic beverage template

An original botanical soda storefront built around one continuous scroll-directed product journey. A pinned cinematic stage moves the product through three visual worlds before opening into a complete flavour collection, serving ritual, and functional bag flow.

## Original art direction

The can, liquid world, and botanical ingredient landscape are original AI-generated project assets. They are stored locally, optimized as WebP, and create no runtime dependency. The FANTA repository was studied only as an interaction benchmark; no source, brand assets, copy, or layout were reused.

## Interaction

- 360vh pinned product journey with scroll-scrubbed position, rotation, scale, and scene crossfades
- Layered bubbles, refracted light, grid depth, kinetic typography, and flavour-lineup assembly
- IntersectionObserver reveals and a reduced-motion path
- Working menu, flavour selection, bag drawer, add-to-bag controls, and anchor navigation
- Five palette builds through the vibecodng palette contract

## Run

```bash
npm install
npm run dev
```
