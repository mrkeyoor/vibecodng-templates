# Orbit

A responsive project workspace with filterable Kanban lanes, movable tasks, progress metrics, team context, and a working task composer.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the projects workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```
