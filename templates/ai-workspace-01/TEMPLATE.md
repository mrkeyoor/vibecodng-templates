# Aperture

Aperture is a dark collaborative AI workspace template with conversation history, a model selector, source-aware answers, prompt suggestions, file context, adjustable reasoning controls, a working composer, and responsive panels for product teams.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the ai workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```

## Palette contract

The template uses `--bw-accent`, `--bw-surface`, `--bw-text`, and `--bw-muted`. Pass a JSON palette through `BW_PALETTE` during a Vite build to create a themed variant.
