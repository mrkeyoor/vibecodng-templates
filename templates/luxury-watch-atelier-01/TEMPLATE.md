# Aster Vale — Calibre Atelier

An original haute-horlogerie template built as a calibre bench that opens. Its flagship is a code-native 3D mechanical movement: scroll or explicit controls separate the case, gear train, bridges, dial and hands along their assembly axis; the crown changes the displayed mechanical state.

## Signature features

- Demand-rendered React Three Fiber calibre made from local geometry—no stock watch image or runtime asset request.
- Bounded scroll-linked exploded assembly with explicit assembled/train/open and crown controls.
- Functional train ledger, code-native finishing loupe and six-position timing certificate.
- Collector material tray resolving into an inline allocation dossier and validated success certificate.
- Mobile-specific watchmaker loupe, vertical parts tray and thumb-reachable bench controls.
- Semantic `BW_PALETTE`, reduced-motion, keyboard and 200% reflow support.

All names, prices, edition figures, calibre specifications and timing measurements are fictional sample content.

## Editorial assets

`watch-macro.webp` and `watch-wrist.webp` are original AI-generated campaign frames created with OpenAI image generation for this template, inspected manually, optimized locally to WebP, and shipped without external runtime dependencies.

## Run

`npm install && npm run dev` or `npm run build`.
