# Common Ground

Common Ground is a bold conference template with ticket conversion, day-by-day schedule controls, accessible session cards, speaker profiles, venue information, live capacity states, sponsor space, and a responsive visual system for a three-day event.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the event workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```

## Palette contract

The template uses `--bw-accent`, `--bw-surface`, `--bw-text`, and `--bw-muted`. Pass a JSON palette through `BW_PALETTE` during a Vite build to create a themed variant.
