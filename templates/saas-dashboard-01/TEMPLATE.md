# Northstar

Northstar is a complete responsive SaaS dashboard template with a collapsible navigation rail, date-range controls, KPI cards, a CSS revenue chart, project health, an actionable task table, team activity, billing links, and keyboard-visible controls.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the dashboard workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```

## Palette contract

The template uses `--bw-accent`, `--bw-surface`, `--bw-text`, and `--bw-muted`. Pass a JSON palette through `BW_PALETTE` during a Vite build to create a themed variant.
