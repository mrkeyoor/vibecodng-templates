# LOUDER / Streetwear Block Party

An original image-led streetwear T-shirt template built around a cheerful block-party campaign and a three-person crew mixer. Desktop behaves like a wide sound-system stage; mobile becomes a one-hand festival crew-pass story.

## Signature interaction

Visitors assign a tee colour, graphic and size to each of three crew members. The photographed group composition, order lines, total and ready state update before an inline fictional drop pass can be issued. The outcome explicitly takes no payment and represents no live inventory.

## Original assets

All five campaign images were generated for this template with the built-in OpenAI ImageGen workflow on 2026-08-21, then optimized locally to WebP. They depict fictional adults and contain no licensed third-party marks:

- `louder-hero.webp` — six-person sunny block-party arrival
- `louder-jump.webp` — kinetic basketball-court celebration
- `louder-portrait.webp` — three-person crew styling portrait
- `louder-print.webp` — macro screen-print craft proof
- `louder-rooftop.webp` — golden-hour rooftop chorus

The coordinated prompt set specified real human expressions, recurring models and garments, direct-flash editorial photography, safe mobile crops, unbranded abstract graphics, and no text or watermark.

## Palette support

`BW_PALETTE` is supported at build time. Semantic surface, text, muted and accent values are injected without changing interaction state meaning.
