# BLOCK/CTRL — WordPress Product Foundry

An original fictional WordPress product studio built around a release foundry that compiles a theme and plugin stack into a clear launch manifest.

## Product journey

- Browse three distinct block-theme specimen worlds.
- Review a WordPress-specific plugin release ledger and compatibility signals.
- Combine a theme, optional plugins, and support channel in a working stack compiler.
- Validate and issue a fictional build manifest with a deterministic reference.

All prices, compatibility signals, performance estimates, download counts, and release data are illustrative demo content. No checkout, download, WordPress installation, or external request occurs.

## Assets

`foundry-commerce.webp`, `foundry-editorial.webp`, and `foundry-hospitality.webp` are original generated assets created specifically for this template, stored locally, and optimized to WebP. They contain no external runtime dependency.

## Motion and accessibility

Framer Motion drives product-specific browser compilation, plugin sockets, state transitions, and scroll-linked chassis movement. Reduced-motion mode stops parallax and decorative loops while preserving all content and state changes. The template supports keyboard use, 320px reflow, 200% text scaling, and the `BW_PALETTE` contract.
