# Still

A polished appointment-booking flow with selectable services, week navigation, available time slots, booking summary, and confirmation state.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the booking workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```
