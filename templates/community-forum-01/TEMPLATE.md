# Commonroom

A friendly community forum with topic filters, discussion search, reactions, bookmarks, member context, and a functional post composer.

## Included

- Responsive React 19 and Vite implementation
- Working first-party UI interactions for the community workflow
- Keyboard-visible focus states and semantic controls
- Four-role palette variables with five public palette builds
- No external component source or runtime service required

## Run locally

```bash
npm install
npm run dev
```
