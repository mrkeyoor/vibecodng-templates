# NOMA — Fashion in Motion

An original fictional fashion label presented through a cinematic campaign, a scroll-controlled lookbook and a working quick-shop experience. Three coordinated photographs build one campaign world without relying on any real label, property or trademark.

## Run locally

```bash
npm install
npm run dev
```
