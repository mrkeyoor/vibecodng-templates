# Northline Aviation — Private Charter Dispatch

An original private-aviation template shaped as a flight dossier that clears. Rather than browsing destination cards, visitors build a real route profile and receive an illustrative aircraft recommendation, operating context and enquiry-ready boarding wallet.

## Signature features

- Demand-rendered 3D route globe with real city coordinates, illuminated route arc and explicit east/west controls.
- Arrival changes stay connected to the dispatch dossier instead of acting as decorative animation.
- Dispatch-table hero with route plot, time zones and live dossier status.
- Origin, destination, party, range and priority matching flow.
- Cleared perforated flight dossier with aircraft, block-time and range context.
- Mission-led fleet selector with mobile previous/next controls.
- Cabin protocol and operating-standard timeline.
- Validated enquiry handoff and explicit operator-confirmation language.
- Purpose-built mobile boarding-wallet composition.
- Semantic `BW_PALETTE`, reduced-motion and 200% text-scaling support.

## Asset provenance

`aircraft-apron.webp` and `cabin-daylight.webp` are original AI-generated images created with OpenAI's built-in image-generation tool for this template on 2026-08-19. Both are local optimized WebP files with distinct mapped roles. The project has no stock images, copied aircraft branding, external fonts or external runtime dependencies.

All routes, times, availability, fleet names and operating details are illustrative. Final aircraft suitability, routing, crew, permits, weather and operational control remain with the licensed operator and flight crew.
